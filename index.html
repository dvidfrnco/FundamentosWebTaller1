Definiciones

HTML
HyperText Markup Language es un lenguaje utilizado para crear la estructura de una paginas web, que permite colocar titulos, imagenes, videos, etc.
CSS
Es un lenguaje utilizado para darle diseño a una pagina web, unido con el HTML, que permite modificar la apariencia visual.
JavaScript
Es un lenguaje de programación utilizado para hacer que una pagina web sea dinamica e interactiva.

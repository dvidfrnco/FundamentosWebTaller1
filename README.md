## Verificacion de codigo

### Caso A

Problema identificado:
La etiqueta <img> utiliza "href" en lugar de "src".

Correccion realizada:
Se reemplaza "href" por "src":
<img src="multimedia/perfil.jpg" alt="Fotografia del estudiante">

Fuente consultada:
MDN Web Docs - Elemento <img> (https://developer.mozilla.org/es/docs/Web/HTML/Element/img)


### Caso B

Problema identificado:
La etiqueta <a> utiliza "src" en lugar de "href".

Correccion realizada:
Se reemplaza "src" por "href":
<a href="https://developer.mozilla.org/">Consultar MDN</a>

Fuente consultada:
MDN Web Docs - Elemento <a> (https://developer.mozilla.org/es/docs/Web/HTML/Element/a)


### Caso C

Problema identificado:
La etiqueta <source> utiliza "href" en lugar de "src".

Correccion realizada:
Se reemplaza "href" por "src":
<source src="multimedia/video.mp4" type="video/mp4">

Fuente consultada:
MDN Web Docs - Elemento <source> (https://developer.mozilla.org/es/docs/Web/HTML/Element/source)


### Caso D

Problema identificado:
"correo" no es valido para "type" de <input>. Debe ser "email".

Correccion realizada:
Se reemplaza "correo" por "email":
<input type="email" name="correo">

Fuente consultada:
MDN Web Docs - <input type="email"> (https://developer.mozilla.org/es/docs/Web/HTML/Element/input/email)


### Caso E

La afirmacion es:
Falsa

Justificacion:
La etiqueta <image> no existe en HTML, la etiqueta correcta para imagenes es <img>. Ademas, <img> no lleva una etiqueta de cierre, como </img>.

Fuente consultada:
MDN Web Docs - Elemento <img> (https://developer.mozilla.org/es/docs/Web/HTML/Element/img)
